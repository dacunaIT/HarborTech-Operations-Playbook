# HarborTech Operations Playbook

This repository contains weekly cloud operations investigation notes, evidence, analysis, recommendations, and lessons learned completed for HarborTech support scenarios.

## Weekly Entries

- [Week 1: Cloud Operations Onboarding](week01-cloud-operations-onboarding.md)
- [Week 2: IAM and AWS CLI Investigation](week02-iam-cli.md)
- [Week 3 - Systems Manager and S3](week03-systems-manager-s3.md)

## Purpose

The purpose of this playbook is to document cloud operations work using a professional process: observe, verify, document, analyze, recommend, and escalate.

Each weekly entry records the evidence reviewed, technical findings, operational analysis, recommendations, escalation notes, lessons learned, and professional vocabulary.
